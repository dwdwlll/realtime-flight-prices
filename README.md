# 实时航班价格查询系统

## 项目简介

这是一个用 Python 开发的实时航班价格查询系统，支持多城市行程规划（包括大于3个途径地）、实时价格刷新，并能将可行方案按价格从低到高排序输出在命令行窗口。

## 功能特性

### ✈️ 核心功能
- **多城市行程规划**：支持任意数量的途径城市（可以大于3个）
- **航班搜索**：从多个航空公司搜索航班信息
- **价格排序**：自动按总价从低到高排序所有可行方案
- **实时刷新**：手动刷新或自动刷新（每10秒）获取最新价格
- **中文界面**：完整的中文用户界面，使用友好

### 🎯 支持的航空公司
- 中国国航
- 南方航空
- 东方航空
- 海南航空
- 厦门航空
- 深圳航空
- 四川航空
- 山东航空
- 春秋航空
- 吉祥航空

## 使用说明

### 主菜单选项

程序启动后会显示主菜单：

```
1. 新建搜索
2. 刷新价格
3. 自动刷新（每10秒）
4. 查看当前结果
5. 退出
```

### 操作流程

#### 1. 新建搜索

选择选项 `1`，然后输入行程城市。

**输入格式：**
- 用逗号分隔：`北京,上海,广州,深圳`
- 用空格分隔：`北京 上海 广州 深圳`

**示例：**
```
请输入城市列表: 北京,上海,广州,深圳
```

支持的城市包括但不限于：
- 北京、上海、广州、深圳
- 成都、杭州、西安、重庆
- 武汉、南京、天津、郑州
- 长沙、沈阳、青岛、厦门
- 大连、昆明、哈尔滨、济南

#### 2. 查看搜索结果

系统会自动搜索每个航段的航班，并生成所有可行的组合方案，按总价从低到高排序。

**结果示例：**
```
行程路线: 北京 -> 上海 -> 广州 -> 深圳
找到 50 个可行方案（已按价格从低到高排序）

方案 1:
行程路线: 北京 -> 上海 -> 广州 -> 深圳
总价: ¥2242.81
航班详情:
    航班东方4626 | 东方航空 | 北京->上海 | 07:15-11:26 | ¥846.98
    航班东方2530 | 东方航空 | 上海->广州 | 06:45-08:19 | ¥817.68
    航班深圳5172 | 深圳航空 | 广州->深圳 | 18:15-21:40 | ¥578.15
```

#### 3. 刷新价格

选择选项 `2` 可以手动刷新价格，获取最新的航班信息和价格。

#### 4. 自动刷新

选择选项 `3` 进入自动刷新模式，系统会每10秒自动更新价格。按 `Ctrl+C` 可以退出自动刷新模式。

#### 5. 查看当前结果

选择选项 `4` 可以重新查看上次搜索的结果。

## 程序架构

### 核心类

#### Flight（航班类）
存储单个航班的信息：
- 航班号
- 航空公司
- 出发地/目的地
- 出发/到达时间
- 价格

#### Itinerary（行程类）
存储完整行程方案：
- 航班列表
- 总价格
- 路线信息

#### FlightSearchEngine（航班搜索引擎）
负责：
- 搜索航班信息
- 规划多城市行程
- 生成所有可行组合
- 按价格排序

#### FlightPriceApp（主应用类）
负责：
- 用户界面交互
- 菜单管理
- 结果显示
- 自动刷新控制

## 技术特点

### 1. 模拟数据系统
由于实际航空公司 API 需要授权和密钥，本系统使用模拟数据生成机制：
- 生成真实感的航班号、时间、价格
- 模拟价格波动（每次刷新价格会变化）
- 支持缓存机制提高性能

### 2. 行程组合算法
- 递归生成所有可能的航班组合
- 限制返回数量避免组合爆炸（最多50个方案）
- 智能排序确保最优方案在前

### 3. 用户体验优化
- 清晰的中英文双语标题
- 实时显示搜索进度
- 显示最后更新时间
- 支持键盘中断（Ctrl+C）
- 屏幕自动清理保持界面整洁

- 其他符合REST标准的航班API

## 注意事项

1. **模拟数据**：当前版本使用模拟数据，价格和航班信息仅供演示使用
2. **网络连接**：如需对接真实 API，确保网络连接正常
3. **编码问题**：程序自动处理 UTF-8 编码，Windows 用户无需额外配置
4. **性能考虑**：多城市（4个以上）行程会产生大量组合，搜索时间可能较长

## 常见问题

### Q: 如何输入更多城市？
A: 直接在输入城市时添加更多城市即可，用逗号或空格分隔，例如：`北京,上海,广州,深圳,杭州,成都`

### Q: 为什么价格会变化？
A: 程序模拟了真实的价格波动，每次刷新会生成新的价格数据。在实际应用中，这些数据会来自真实 API。

### Q: 可以保存搜索结果吗？
A: 当前版本不支持保存，但可以通过复制粘贴保存到文本文件。未来版本可以添加导出功能。

### Q: 支持国际航线吗？
A: 架构上支持，只需在 `CITIES` 列表中添加国际城市名称即可。
